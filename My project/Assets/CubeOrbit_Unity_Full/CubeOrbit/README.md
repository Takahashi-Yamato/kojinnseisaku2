# CUBE ORBIT

宇宙に浮かぶブロックの上でキューブを転がして、ゴールを目指す3Dパズルアクションです。
ブラウザでそのまま遊べる **Web版** と、ステージを増やしていける **Unity版** があります。

## 遊び方

キューブを1マスずつ転がして、**色の付いた台（ゴール）** に乗せるとクリアです。
途中にある小さいキューブ（ジェム）を集めると、ランクが上がります。

- 1段の段差ならよじ登れます。2段以上は登れません
- 高いところからは飛び降りられます
- 端から外に出ると宇宙へ落ちて、最後に通ったチェックポイントからやり直しです

### 操作

| 操作 | キーボード | スマホ・マウス |
|---|---|---|
| 転がる | 矢印キー / WASD（↑ = 画面の右上） | スワイプ、または画面の四隅をタップ |
| やり直し | R | 右下の ↺ |
| ポーズ | Esc / P | 右下のボタン |
| サウンドON/OFF | M | ポーズ画面（Web版は右下の ♪ も） |
| 決定・演出を飛ばす | Enter / Space | タップ |
| 記録を消して最初から | Delete / Backspace（タイトル・ポーズ・クリア画面で） | タイトルやポーズ画面のボタン |

画面は斜め上から見下ろしているので、グリッドの向きと画面の向きは45度ずれています。
↑キーで画面の右上、→キーで右下、↓キーで左下、←キーで左上へ転がります。

## ギミック

| ギミック | 見た目 | 動き |
|---|---|---|
| スイッチ | 床の白い板 | 踏むと、同じ色の **透明ブロック**（枠だけのブロック）が実体化して道になる |
| 動く床 | 青いブロック（上面が光る） | 2点の間を往復する。止まっている間だけ乗り降りでき、乗ると一緒に運ばれる |
| エレベーター | 青いブロック | 縦に動く床。高い段へ運んでくれる |
| 押し出す壁 | オレンジのブロック | 一定間隔で1マス飛び出し、前にいるキューブを押し出す。飛び出す直前に点滅する |
| 崩れる床 | ひびの入った茶色いブロック | 乗ると約0.5秒で崩れる。落ちてやり直すと元に戻る |
| チェックポイント | 床の小さいマーク | 通ると、落ちた時にここから再開する |

動く床が来ていない穴には、キューブが自分から転がり込まないようになっています（待っていれば床が来ます）。

## スコア

ステージをクリアすると、次の合計がスコアになります。プレイ中も画面右上に、集めたキューブの分の点数が出ます。

| 内訳 | 点数 |
|---|---|
| キューブ | 1個につき 1,000点 |
| タイムボーナス | 目安タイムの2倍から、1秒早いごとに 100点 |
| ノーミスボーナス | 3,000点（1回落ちるごとに −1,000点、最低0点） |
| クリアボーナス | 5,000点 |

- ステージごとのベストスコアが保存され、更新すると **NEW RECORD!** と出ます
- タイトル画面には、全ステージのベストスコアを足した **TOTAL SCORE** が出ます
- ゲームクリア画面にも **合計スコア** が出ます
- Unity版は、点数の配分を `GameManager` のインスペクター（スコアの項目）で変えられます

### 記録を消して最初から

タイトル画面・ポーズ画面・クリア画面で **Delete（またはBackspace）** を押すか、「記録を消して最初から」ボタンを押すと確認が出ます。
「消して最初から」を選ぶと、スコア・ベストタイム・集めたキューブの記録がすべて消えて、ステージ1から始まります。元には戻せません。

## ランクの決まり方

### ステージごと（S / A / B / C）

| 要素 | 配点 |
|---|---|
| 集めたキューブの割合 | 60点 |
| タイム（目安タイムの2倍を0点として、早いほど高い） | 30点 |
| 落下回数（0回で10点、1回ごとに −3点） | 10点 |

88点以上がS、72点以上がA、50点以上がB、それ未満がCです。

### ゲームクリア画面の総合ランク

- **Web版**：クリアしたステージの割合（50点）＋ キューブを集めた割合（30点）＋ タイム（各ステージの目安タイムの合計と比べる、20点）。92点以上がS、78点以上がA、60点以上がB
- **Unity版**：クリアしたステージの割合（70点）＋ タイム（「1ステージあたりの目標タイム × ステージ数」と比べる、30点）。95点以上がS、80点以上がA、60点以上がB

Unity版は、各ステージのキューブの総数をゲームクリア画面から読めないので、キューブはランクに入れていません。

記録は自己ベスト（最速タイム・最多キューブ・最高スコア）だけが保存されます。Web版はブラウザに、Unity版は PlayerPrefs に保存されます。

## Web版

### 中身

- `index.html` 1ファイルだけで動きます。外部のライブラリは使っていません（3D描画はWebGLを直接使用）
- 文字は Google Fonts（DotGothic16 / Press Start 2P）を読み込みます。オフラインでも遊べますが、文字が普通のフォントになります
- 効果音はブラウザの Web Audio で鳴らしています（音声ファイルなし）

### 画面の流れ

```
タイトル ─┬─ スタート ─────→ ステージ1 → 2 → … → 15 → ゲームクリア画面
          └─ ステージ選択 ─→ 好きなステージ（全クリア後は「ゲームクリア画面を見る」も出る）
```

### ステージを追加・変更するには

`index.html` の中の `const LEVELS = [ ... ]` に、ステージが1つずつオブジェクトで書かれています。
1つ追加すればステージ選択に自動で並びます。座標は `x` が画面の右下方向、`z` が左下方向、`y` が上です。

```js
{ name:"ステージ名", hint:"開始時に出す説明（なくてもOK）", start:[1,1], par:45,
  rects:[[0,0,2,2,0], [0,-7,2,-5,1]],      // 床: [x0, z0, x1, z1, 上面の高さ]（下は暗闇まで伸びる）
  maps:[{x0:3, z0:-6, rows:["0.0", "000"]}], // 1マスずつ描く床: 数字=高さ, .=穴
  ghosts:[[3,0,1,5,0,1, 1]],               // 透明ブロック: [x0,y0,z0, x1,y1,z1, スイッチ番号]
  switches:[[2,0, 1]],                     // スイッチ: [x, z, 番号]
  checkpoints:[[1,-6]],                    // [x, z]
  gems:[[1,-3], [4,2,1]],                  // [x, z]（床の上に自動で乗る）か [x, y, z]
  goal:[1,-6],                             // [x, z]
  movers:[{a:[1,0,-1], b:[1,0,-4], off:0.8}],        // 動く床: a⇔b を往復（b の y を変えるとエレベーター）
  pushers:[{at:[0,1,-3], dir:[1,0,0], off:0.7}],     // 押し出す壁: at から dir の向きに飛び出す
  crumbles:[[1,0,-1], [1,0,-2]],                     // 崩れる床: [x, y, z]
}
```

- `par`：ランク計算の目安タイム（秒）
- `off`：動く床・押し出す壁のタイミングをずらす秒数。並べた壁を 0 / 0.7 / 1.4 にすると順番に飛び出します
- 動く床には `speed`（初期値2.2マス/秒）と `pause`（止まる時間、初期値1.4秒）、押し出す壁には `period`（周期、初期値2.2秒）も書けます

## Unity版

### 動作環境

- Unity 2022.3 LTS / Unity 6
- **3D (Built-in)** でも **Universal 3D (URP)** でも動きます。HDRP では表示されません
- 旧Input Manager・新Input System のどちらの設定でも動きます

### はじめ方

1. `CubeOrbit` フォルダを、Unityプロジェクトの `Assets` に入れる
2. **Tools > Cube Orbit > 1. 初期セットアップ** を押す（マテリアルとプレハブが自動でできる）
3. **Tools > Cube Orbit > ステージエディタ** を開いて、**「サンプル15ステージを生成」** を押す（Web版の15ステージがシーンになる）
4. **Tools > Cube Orbit > 3. タイトル画面を作る** を押す（Build Settings の先頭にタイトルが入る）
5. ゲームクリア画面を作る（下の「ゲームクリア画面の設定」を参照）
6. `CubeOrbit/Stages/Title` を開いて ▶ で遊べます

### Build Settings の並び

```
0番        Title       … タイトル画面・ステージ選択
1〜15番    Sample01〜15 … ステージ
16番〜     自分で作ったステージ
一番最後   Result      … ゲームクリア画面
```

クリアすると Build Settings の次のシーンへ進みます。順番は **File > Build Settings** でドラッグして変えられます。
**`Result` は必ず一番最後** にしてください。自分より前のシーンを全部ステージとして集計します。

### ゲームクリア画面の設定

ゲームクリア画面は `ResultScreen.cs` が、カメラ・星空・花火・紙吹雪・回るキューブ・ファンファーレを全部自動で作ります。

1. `ResultScreen.cs` を `CubeOrbit/Scripts/Game` に入れる
2. **File > New Scene** で空のシーンを作り、`CubeOrbit/Stages` に **`Result`** という名前で保存する
3. 空のオブジェクト（Create Empty）を作って `ResultScreen` を追加する
4. **File > Build Settings** で `Result` を **一番最後** に追加する

最新の `TitleScreen.cs` は、Build Settings の最後にある `Result` を自動でステージ一覧から外します（以前お伝えした1行の追加は不要です）。

最後のステージのクリア画面で「次のステージ」を押すと、ゲームクリア画面に進みます。
演出は約6秒で、途中でEnterかクリックをすると飛ばせます。

`ResultScreen` のインスペクターで変えられるもの：

| 項目 | 内容 |
|---|---|
| Title / Message / Thanks | 表示する文字 |
| Target Seconds Per Stage | 総合ランクの目標タイム（1ステージあたり、初期値40秒） |
| Firework Interval / Firework Sparks | 花火の間隔と火花の数 |
| Confetti Per Second | 紙吹雪の量 |
| Ring Cubes | 中央のキューブのまわりを回るキューブの数 |
| Volume | 音量 |
| Title Scene Name / First Stage Build Index | 戻り先のタイトルと、最初のステージの番号 |

## Unity版でステージを作る

### 1. 新しいステージを作る
ステージエディタの **「新しいステージ」** を押して、名前（例：`Stage16`）と保存場所を決めます。
カメラ・プレイヤー・スタート床・ゴールが入ったシーンができて、Build Settings の最後に追加されます。
**追加したら、`Result` が一番最後のままになるように並べ替えてください。**

### 2. ステージ情報を入れる
シーン内の `GameManager` を選んで設定します。

| 項目 | 内容 |
|---|---|
| Stage Name | 画面左上に出る名前 |
| Stage Number | 画面に出す番号（例：16）。0ならBuild Settingsの順番から自動 |
| Hint | 開始時に画面下に出る説明 |
| Par Time | ランク計算の目安タイム（秒） |
| Auto Kill Y | 一番低いブロックの少し下を、自動で落下ラインにする |
| Next Scene Name | 空なら Build Settings の次のシーンへ |

### 3. クリックで置く
1. ステージエディタの **「置く物」** から選ぶ
2. シーンビューをクリックすると置かれます
   - **ブロックの面をクリック** → その面の隣のマスに置かれる
   - **何もない所をクリック** → 「何もない所の高さ」の高さに置かれる
   - **Shift+クリック** → 削除
   - **Ctrl+Z** → 元に戻す
3. 置いた物を選ぶと、インスペクターで数値を調整できます

- ブロックは `size` を変えるだけで、床・通路・壁・柱になります。「下に伸ばす」を3〜4にすると、下の暗闇から生えている見た目になります
- ジェム・スイッチ・チェックポイント・ゴールは、床の **1つ上のマス** に置きます（床の上面をクリックすれば自動でそうなります）
- 押し出す壁は、壁ブロックの表面のマスに重ねて置きます（壁に穴を開ける必要はありません）

### 4. 確かめる
1. **「ステージを検証」** を押す → ゴールとジェム全部にたどり着けるかを総当たりで調べて、取れないジェムを教えてくれます
2. ▶ で実際に遊ぶ → 動く床や押し出す壁の **タイミング** は検証ではわからないので、ここで確認します

### 作るときのコツ

- 動く床と押し出す壁は、すべて **ステージ開始からの時間** で動きます。`timeOffset` をずらすだけで「交互に動く」「順番に動く」が作れます
- 押し出す壁の間には、安全なマスを1つ空けると遊びやすくなります
- 動く床を待つ場所は普通のブロックにしてください。崩れる床だと、待っている間に落ちてしまいます
- 既存のステージを改造したい時は、シーンを Ctrl+D で複製して名前を変え、Build Settings に追加すると楽です

### 調整できる主な数値

| 対象 | スクリプト | 主な数値 |
|---|---|---|
| キューブの動き | `PlayerCube` | 転がる時間、よじ登る時間、重力、押し出され時間、出現・ゴール演出 |
| 入力 | `CubeInput` | ↑キーの画面上の向き、スワイプの距離、タップ移動、先行入力の時間 |
| 動く床 / エレベーター | `MovingPlatform` | 移動量、速さ、止まる時間、タイミングずらし、乗り降りの猶予 |
| 押し出す壁 | `Pusher` | 向き、周期、タイミングずらし、飛び出し・停止・戻りの時間、予告の点滅 |
| 崩れる床 | `CrumbleTile` | 崩れるまでの時間、震え、落ちる速さ |
| 透明ブロック / スイッチ | `GhostBlockVolume` / `FloorSwitch` | スイッチ番号、出現アニメの速さ |
| カメラ | `CameraFollow` | 見下ろす角度、ズーム、追従の速さ、揺れ |
| 効果音 | `SoundPlayer` | 音量。自分の AudioClip を入れれば差し替え（入れない音は電子音を自動生成） |
| 画面表示 | `StageHUD` | 文字サイズ、色、ヒントが消えるまでの手数 |
| タイトル | `TitleScreen` | タイトル文字、サブタイトル、文字の大きさ、色が流れる速さ |
| スコア | `GameManager` | キューブ1個の点数、タイムボーナス、ノーミスボーナス、クリアボーナス |

### 1フレームの流れ

1. `GameManager` がステージ開始からの時間（`StageTime`）を進める
2. 動く床・押し出す壁・崩れる床が、`StageTime` から自分の状態を計算する
3. `PlayerCube` が入力を受け取り、`MoveRules.Resolve()` で行き先を決めてアニメーションする
4. マスに着いたら、そのマスにある物（ジェム・スイッチ・崩れる床など）に知らせる

### 新しいギミックを作るには

`GridElement` を継承して、必要なところだけ上書きします。

```csharp
using UnityEngine;
namespace CubeOrbit
{
    [ExecuteAlways]
    public class MyGimmick : GridElement, IPlayerEnterHandler
    {
        public float myValue = 1f;   // インスペクターで調整できる

        // そのマスが固いか（進めない・上に乗れる）
        public override bool Blocks(Vector3Int c) { return c == Cell; }

        // ステージ検証から見た固さ（時間を無視）
        public override bool SolverSolid(Vector3Int c, int mask) { return c == Cell; }

        // プレイヤーがこのマスに入った時
        public void OnPlayerEnter(PlayerCube player, bool passingThrough) { }
    }
}
```

| 上書きできるもの | 意味 |
|---|---|
| `Blocks(c)` | 固い（進めない） |
| `Climbable(c)` | よじ登れる（初期設定は Blocks と同じ） |
| `IsFloor(c)` | 上に立てる（初期設定は Blocks と同じ） |
| `BodyWait(c)` / `FloorWait(c)` | 今は入らずに待つ（動く床の通り道など） |
| `SolverSolid(c, mask)` | ステージ検証用の固さ |
| `IPlayerEnterHandler` | プレイヤーがこのマスに入った |
| `IPlayerLandHandler` | プレイヤーがこのブロックの上に乗った |
| `IStageResettable` | 落ちてやり直す時に元に戻す |

## よくある質問

**Q. Unity版がピンク色になる**
シェーダーが読み込めていません。`Shaders` フォルダが入っているか、HDRP ではないかを確認して、もう一度「初期セットアップ」を押してください。

**Q. ステージ選択にゲームクリア画面がステージとして並ぶ**
`TitleScreen.cs` を最新版にして、ゲームクリア画面のシーン名を `Result` にしてください。

**Q. ゲームクリア画面の数字がおかしい**
Build Settings で `Result` が一番最後になっているか確認してください。`Result` より前のシーンをステージとして集計します。

**Q. 操作の向きを変えたい**
Unity版はプレイヤーの `CubeInput > Up Key Screen Angle` を変えます（0 = 真上、45 = 右上）。カメラの角度を変えても、操作は画面の見た目に合わせて自動で変わります。

**Q. カメラをもっと寄せたい**
Unity版は `Main Camera > CameraFollow > Orthographic Size` を小さくします。

**Q. 効果音を差し替えたい**
Unity版は `GameManager > SoundPlayer > Sounds` に、種類と AudioClip を追加します。

**Q. 記録を消したい**
タイトル画面で Delete を押すか「記録を消して最初から」を押してください（Web版・Unity版共通）。
