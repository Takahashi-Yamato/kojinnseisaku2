タイトル
「CUBE ORBIT」

遊び方

キューブを1マスずつ転がして、色の付いた台（ゴール） に乗せるとクリアです。 途中にある小さいキューブ（ジェム）を集めると、ランクが上がります。

1段の段差ならよじ登れます。2段以上は登れません
高いところからは飛び降りられます
端から外に出ると宇宙へ落ちて、最後に通ったチェックポイントからやり直しです


操作


操作	キーボード	スマホ・マウス


転がる	矢印キー / WASD（↑ = 画面の右上）	スワイプ、または画面の四隅をタップ
やり直し	R	右下の ↺
ポーズ	Esc / P	右下のボタン
サウンドON/OFF	M	ポーズ画面（Web版は右下の ♪ も）
決定・演出を飛ばす	Enter / Space	タップ


画面は斜め上から見下ろしているので、グリッドの向きと画面の向きは45度ずれています。 ↑キーで画面の右上、→キーで右下、↓キーで左下、←キーで左上へ転がります。


ギミック


ギミック	見た目	動き
スイッチ	床の白い板	踏むと、同じ色の 透明ブロック（枠だけのブロック）が実体化して道になる
動く床	青いブロック（上面が光る）	2点の間を往復する。止まっている間だけ乗り降りでき、乗ると一緒に運ばれる
エレベーター	青いブロック	縦に動く床。高い段へ運んでくれる
押し出す壁	オレンジのブロック	一定間隔で1マス飛び出し、前にいるキューブを押し出す。飛び出す直前に点滅する
崩れる床	ひびの入った茶色いブロック	乗ると約0.5秒で崩れる。落ちてやり直すと元に戻る
チェックポイント	床の小さいマーク	通ると、落ちた時にここから再開する

動く床が来ていない穴には、キューブが自分から転がり込まないようになっています（待っていれば床が来ます）。
